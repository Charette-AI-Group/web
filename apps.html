About These Numbers

Each count is a cumulative total since the app's first version, read when you open this page and remembered in your browser so it is not fetched again on every visit. Desktop applications are counted by GitHub: every download of a published release file, which leaves out copies of the source taken with the green Code button, since those are counted nowhere. The Obsidian plugins are counted by Obsidian, which is the honest number for a plugin — almost everyone installs it from the community directory, and GitHub never sees those. Obsidian publishes a fresh snapshot once a day, so that figure can sit up to a day behind the one on its directory page. A dash means the source could not be reached just now, not that the number is zero.
