SAE Fractional Calculator

Objectives

A desktop calculator built for DIY and construction projects that use imperial (SAE) measurements. Lengths are entered the way you say them — yards, feet, inches, and fractions of an inch — and every computation is done exactly on a 1/32″ grid, so results always land on your tape measure.

  • Natural entry: 1 ft 6 in 1 /2 + 2 ft 5 in 3 /4 = gives 4′ 0-1/4″
  • Dedicated denominator keys (/2, /4, /8, /16, /32) — impossible to enter a fraction that is not on the grid
  • Exact arithmetic in integer 1/32″ units; results always shown in feet-inches with reduced fractions
  • Full keyboard entry, light and dark themes

Download

Free standalone application for Windows and macOS — nothing else needs to be installed for it to run.

Download for Windows Download for macOS Source on GitHub

Both download buttons bring you to the GitHub release page: scroll down to the Assets section. For Windows, click saeCalculatorSetup-version.exe to install it properly, with Start menu and desktop shortcuts and no administrator rights needed — or saeCalculator.exe to run a single file without installing anything. For macOS, click saeCalculator-macos.zip.

Windows may show a SmartScreen notice on first run because the download is unsigned; choose "More info", then "Run anyway".

The macOS build is for Apple Silicon Macs (M1 or newer) and does not run on Intel Macs. It is unsigned, so the first time you open it, right-click the app and choose “Open” rather than double-clicking. If macOS says instead that the app “is damaged”, it is not — that is Gatekeeper quarantining an unsigned download. Clear it from Terminal with xattr -cr path/to/saeCalculator.app, then open it normally.

Support This Work

The SAE Fractional Calculator is free, has no ads, and collects nothing about you — the browser version does its arithmetic on your own device and sends nothing anywhere, and the desktop app never touches the network at all. That is the way a small tool ought to work, and it is also why tools like this are hard to sustain: there is no data to sell and no subscription to bill, so nothing pays for the work behind them.

Small tools take real time to build and, more importantly, to keep alive. Operating systems change, browsers change underneath them, bugs surface in real use, and features get added because someone asked. A donation, however small, is what makes that continued attention possible — and it directly funds the next free tool as well as the upkeep of this one.

If this calculator saved you a re-cut board or a wasted trip to the lumber yard, please consider chipping in. It genuinely makes the difference between a project that keeps improving and one that quietly stops.
